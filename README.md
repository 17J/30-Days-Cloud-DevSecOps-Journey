# 📖 About This Challenge

Welcome to my **30 Days Cloud & DevSecOps Journey** 🚀

This challenge is focused on building strong fundamentals in:

- Cloud Computing
- AWS
- Linux & Networking
- Docker & Kubernetes
- CI/CD
- DevSecOps & Security Automation
- Monitoring & Observability

The goal is to learn consistently, build projects, and document everything publicly.
